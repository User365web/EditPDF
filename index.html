Frequently asked questions

Are these PDF tools really free?

Yes. All EditPDF tools are free to use, with no account, no watermark and no sign-up.

Are my documents uploaded to a server?

No. Files are processed in your browser. The page loads JavaScript libraries from a public CDN, but your selected files are not sent to those services or to EditPDF.

Which PDF tools are available?

You can merge PDFs, split and extract pages, rotate pages, compress a PDF, convert images (JPG, PNG, WebP) to PDF, count PDF pages and view PDF properties.

Will compression always make my PDF smaller?

Not always. The compression tool re-renders pages as images, which helps scanned and image-heavy files but removes selectable text. The tool shows the new size so you can compare.

Does EditPDF work on phones and tablets?

Yes. The tools run in modern mobile and desktop browsers. Very large files may be slow on older devices.

Can I convert PDF to Word?

Not yet. Reliable PDF-to-Word conversion needs more advanced processing than the current browser-based tools provide.
