How to use Rotate PDF

  1. Choose a PDF. Select the document that needs rotating.
  2. Pick an angle. Choose 90° clockwise, 180°, or 270° clockwise.
  3. Download. Click Rotate PDF and save the corrected file.

About Rotate PDF

Scanners and phone cameras often save pages sideways. Rotating the PDF once fixes the orientation for everyone you share it with, instead of each person rotating the view by hand.

Good to know: this tool rotates every page by the same angle. To rotate only some pages, split them out first, rotate, then merge everything back together.

Rotate PDF — frequently asked questions

How do I rotate a PDF and save it?

Choose your PDF, pick the angle, and click Rotate PDF. The rotated file downloads and keeps the new orientation.

Can I rotate just one page?

This tool rotates all pages. To rotate a single page, extract it with Split PDF, rotate it, and merge it back with Merge PDF.

Does rotating change the quality?

No. The rotation is stored in the PDF page settings; the content is not re-compressed.

Which direction is 90°?

Clockwise. Use 270° for a quarter-turn counter-clockwise.

Are my files uploaded?

No. The tool runs entirely in your browser.
