How to use PDF Info

  1. Choose a PDF. Select a file or drag it into the box.
  2. Click Show information. The tool reads the document's properties.
  3. Review the details. See size, pages, title, author, creator, producer and dates.

About PDF Info

PDF properties show where a file came from and how it was produced. They are useful for checking page size before printing, confirming which version of a document you have, or seeing which program created a file.

Good to know: many PDFs leave some fields empty, and those show as “Not specified”. Properties are stored by the program that made the file and may not always be accurate.

PDF Info — frequently asked questions

What information does the tool show?

File name and size, page count, page size, and the title, author, subject, creator, producer, creation date and modified date when they are present.

Why are some fields empty?

The program that created the PDF did not store them. That is common.

Is it safe for confidential files?

The file is read in your browser and is not uploaded to EditPDF. Avoid shared or public computers for sensitive documents.

Can I edit the properties?

Not in this tool. It is a viewer only.

What is a PDF point?

A unit equal to 1/72 inch. A standard A4 page is about 595 × 842 points.
